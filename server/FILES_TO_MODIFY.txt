【第一阶段 - CRITICAL（必须首先修改）】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🔴 src/lib/db.ts
   优先级: ★★★★★ (最高)
   Prisma 调用数: 2
   重要性: 数据库连接初始化，必须首先修改
   变更内容:
     - 移除 PrismaClient, PrismaBetterSqlite3, PrismaPg 导入
     - 导入 drizzle/db.ts 中的 db 对象
     - 移除 mkdirSync, PrismaClient 初始化代码
     - 替换成 Drizzle 的数据库导出
   示例: 参考 PRISMA_TO_DRIZZLE.md 中的 "连接初始化" 部分

2. 🔴 src/services/schedule.ts
   优先级: ★★★★★ (最高)
   Prisma 调用数: 78
   重要性: 核心业务逻辑，大量数据库操作
   变更内容:
     - findMany() → db.select()
     - create() → db.insert()
     - update() → db.update()
     - delete() → db.delete()
     - where 条件转换为 Drizzle where()
   依赖: 必须在 src/lib/db.ts 修改之后
   示例: 参考 PRISMA_TO_DRIZZLE.md 中的 "SELECT/INSERT/UPDATE 查询"

3. 🔴 src/services/config.ts
   优先级: ★★★★★ (最高)
   Prisma 调用数: 12
   重要性: 配置管理，初始化时需要
   变更内容:
     - SiteSetting CRUD 操作转换
     - 参数化查询处理
   依赖: 必须在 src/lib/db.ts 修改之后

4. 🔴 src/services/requests.ts
   优先级: ★★★★★ (最高)
   Prisma 调用数: 45
   重要性: 请求处理的核心服务
   变更内容:
     - SongRequest 查询操作
     - 复杂的 WHERE 条件
     - 关联查询
   依赖: 必须在 src/lib/db.ts 修改之后
