# REQUIREMENTS — 功能需求与验收

> 需求已与台方确认。改需求先改本文件，再改代码。数值型参数（班数、时段、上限、限流）在后台可配，本文件记录默认值。

## 0. 角色

| 角色           | 权限                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 学生（免登录） | 搜索、试听、提交点歌、凭查询码查状态、查看歌单                        |
| 审核员         | 前述全部 + 试听审核、驳回、排期、调序、下载                           |
| 超级管理员     | 前述全部 + 账号管理、播出时段、行政历、年级班数、敏感词、音源账号配置 |

审核员改不了任何系统配置和账号。首个超管用户名 `yadmin`，密码由环境变量种子生成，首次登录强制修改。

## 1. 前台：搜索与试听

- 搜索框输入关键词，结果区顶部 nav tab 切换音源：网易云 / QQ / 酷狗。
- 每个 tab 独立请求、独立加载态。某音源失败只在该 tab 显示「此音源暂时不可用」，其余照常。
- 结果条目：封面、歌名、歌手、专辑、时长、试听按钮、点歌按钮。
- 试听经后端代理，支持拖动进度（Range 请求）。能取到完整音频就放完整，只能取到片段就放片段并在条目上标注「仅试听片段」。
- 同一时刻只允许一个音频在播。

## 2. 前台：点歌提交

- 点「点歌」弹出确认弹窗（油印点歌条样式），确认前展示歌曲信息与待填字段。
- 字段：年级（高一 / 高二 / 高三）、班级（下拉，默认 1~23 班）、姓名。不设寄语，不设「献给谁」。
- 身份填写是可开关的：超管可在后台关闭「要求填写年级 / 班级 / 姓名」。开启时三项必填；关闭时表单不显示这三项，提交为完全匿名，后台该条显示为「匿名」。
  - 关闭期间「同姓名每天 2 首」这条限流自然失效，只剩 IP 维度。切换开关不影响已有记录。
- 提交成功返回 6 位查询码，以盖章动效呈现，提示学生自行保存。
- 校验与限流：
  - 同 IP 每天最多 10 次提交
  - 同（年级 + 班级 + 姓名）每天最多 2 首，仅在要求填写身份时生效
  - 歌名与提交内容过敏感词表（超管可维护）。命中不直接拒绝，标记后交人工判断。
  - 不做验证码；若实际被刷再接 Cloudflare Turnstile。
  - 不合并多人同点，重复即多条记录。
- 点歌通道默认全天开放，超管可一键关闭并显示公告文案。

## 3. 前台：歌单

- 「最近歌单」= 昨天 + 今天 + 未来所有已排期日期，按日期与时段分组。
- 条目只显示：封面、歌名、歌手、时长、音源角标、时段与播出序号。不显示点歌人任何信息。
- 允许在歌单里直接试听。
- 当前时段高亮并显示 ON AIR 状态。
- 「查看过往歌单」入口：按月分组的日期列表，可直接跳到指定日期。
- 不做本月热门榜。

## 4. 前台：查询状态

凭 6 位查询码查询单条点歌：状态（待审核 / 已排期 / 已播出 / 已驳回）、驳回理由、已排期则显示日期与时段。不显示提交人信息。

## 5. 后台：审核与排期

- 待审核列表：提交时间、歌曲信息、提交人（年级班级姓名）、音源、可试听、敏感词命中标记、实际可下载音质。
- 操作：通过并排期、驳回（必填理由）、批量通过、批量排到某天、拖拽调整同一时段内顺序。
- 状态机：`PENDING` → `SCHEDULED` → `PLAYED`，或 `PENDING` → `REJECTED`。`PLAYED` 由时间自动判定，不需手动点。
- 排期粒度：日期 + 时段 + 顺序号。系统累计该时段总时长与首数，超过配置上限时提示（提示而非硬拦）。
- 只能排到行政历允许播出的日期。周末与法定假日不可排。
- 最远可排到未来 14 天。
- 管理员可自行搜索歌曲直接补录进歌单，不经点歌流程。
- 所有操作写 AuditLog。

## 6. 后台：下载

- 单曲下载：实时从对应音源取流并转发，不在服务器落盘缓存。
- 按天打包：流式 zip，边取边压。文件名 `03_歌名 - 歌手.mp3`，压缩包 `2026-09-02_午间档.zip`。
- 写入 ID3 标签与封面；打包时附带同名 `.lrc` 歌词。
- 取不到可用音频的条目，在压缩包内生成 `缺失清单.txt` 说明，不让整个打包失败。

## 7. 后台：配置（仅超管）

- 播出时段：名称 + 起止时间 + 每档上限。初始值：午间档 12:00–12:30、晚间档 17:40–18:00。
- 行政历：按日期标记 上学 / 不上学 / 考试不播。周末与法定假日默认不播。标为不播的日期不可排期，但点歌通道照常开放，学生可点，只是排到之后的可播日。
- 年级班数：每个年级可单独设置班级数量，默认 23。
- 身份填写开关：是否要求学生填写年级 / 班级 / 姓名，默认要求。关闭后点歌完全匿名。
- 敏感词表：增删改。
- 音源账号：网易云扫码登录拿 Cookie，可查看有效性、可清除。QQ 与酷狗预留位置，当前无账号。
- 账号管理：创建 / 停用审核员账号，重置密码。

## 8. 非功能要求

- 移动优先。前台在 375px 宽度下完整可用，无横向滚动。
- 键盘可达，焦点可见；`prefers-reduced-motion` 下关闭盖章与呼吸灯动效。
- 冷启动之外，首页首屏 2 秒内可交互；字体自托管、不阻塞渲染。
- 前台所有接口无需登录即可访问，但均带限流。
- 站内有一页使用声明，说明音频来自第三方平台、仅用于校内广播。

## 9. 验收清单

- [ ] 三个音源都能搜到结果，任一音源宕掉不影响其他 tab
- [ ] 试听可拖动进度，切歌时上一首停止
- [ ] 提交点歌返回查询码，凭码可查到状态
- [ ] 同 IP 第 11 次提交被拒；同一年级班级姓名当天第 3 首被拒
- [ ] 关闭身份填写开关后，表单不再要求身份、可匿名提交，后台该条显示为「匿名」
- [ ] 未审核的歌不出现在前台歌单
- [ ] 排期到周末或考试日被拒绝
- [ ] 时段超出上限时有提示
- [ ] 单曲下载得到可播放文件，且带 ID3 与封面
- [ ] 按天打包得到 zip，缺失条目有清单说明
- [ ] 审核员访问配置接口返回 403
- [ ] 前台任何页面都查不到点歌人姓名与班级
- [ ] 所有审核与配置操作在 AuditLog 中有记录
- [ ] 375px 宽度下前台无横向滚动
